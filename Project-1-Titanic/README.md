# Titanic Survival Analysis

## Overview
Exploratory data analysis of the Titanic dataset 
(891 passengers) to uncover what factors determined 
survival in the 1912 disaster.

## Key Findings
1. **Gender was strongest predictor** — Women survived 
   at 74% vs men at 19%
2. **Class determined survival** — 1st class 63% 
   vs 3rd class 24%
3. **Wealth = survival** — Survivors paid 2x more on average
4. **Most vulnerable group** — 3rd class men survived 
   at only 13%
5. **Youngest survivor** — 5 month old baby (0.42 years)

## Tools Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## Dataset
- 891 passengers, 12 features
- Source: Kaggle Titanic Competition
